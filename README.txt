Gary Palfreman — Digital Business Card

FILES
- index.html  : animated mobile-friendly digital card
- front.png   : front card artwork
- back.png    : back card artwork

HOW IT WORKS
1. Host this folder on any static web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted URL on a phone.
3. The card automatically performs one 3D flip.
4. Tap the card at any time to flip front/back.
5. Tap “Show QR” to generate a QR code for the live hosted URL.

IMPORTANT
A QR code can only open the card from any phone once index.html has a public URL.
The page generates its own QR from that live URL, so no code changes are needed after hosting.
